# 스토리 템플릿 — 용도별 골격

모든 템플릿은 **긴장 → 리빌 → 증명 → 각인** 리듬을 따른다 (SKILL.md 스토리보드). 괄호 안의 번호는 [typography-playbook.md](typography-playbook.md)의 무브 번호다. 템플릿은 출발점일 뿐이다. 꽂히는 한 문장이 가장 세게 들리도록 순서를 바꿔도 된다.

## A. 랜딩·유튜브 런칭 (16:9, 30초): 기본값

| 시간 | 장면 | 무브 |
|---|---|---|
| 0–3s | 훅: 타깃이 겪는 문제를 단어 3~4개로 끊어 친다. 마지막 단어에 그라데이션 | 템포 컷 ④ + ⑦ |
| 3–3.5s | 정적 | ⑬ |
| 3.5–7s | 리빌: 제품명 → 회색 둘째 줄로 한 줄 소개 | 트래킹 인 ③ + 빛 스윕 ⑧, 투톤 ⑥ |
| 7–23s | 기능 2~3개 (각 5~7초): 투톤 헤드라인 → UI 장면에서 입력 → 결과 | ⑥ + scene-catalog 1·2 |
| 23–26s | 폭 또는 수치 | 기능 월 ⑫ 또는 숫자 히어로 ⑩ |
| 26–30s | 엔드카드: 로고 → 꽂히는 한 문장 → CTA·URL | 락업 |

## B. 쇼츠·릴스 (9:16, 15초)

- 첫 1초 안에 훅. 템포 컷이나 질문 한 줄로 시작한다. 로고로 시작하지 않는다.
- 0–2.5s 템포 컷 훅 → 2.5–4s 제품명 스케일 인 → 4–12s 기능 1~2개 (단어 교체 ⑤ + UI 조각) → 12–15s 락업.
- 템포 키네틱 스타일이 기본이다. 컷 길이는 0.4~1.5초.
- 무음 시청을 전제로 모든 정보를 화면 글자로 보여준다. 글자는 16:9보다 1.2배 크게 쓴다.
- 상단 220px, 하단 320px은 플랫폼 UI가 덮으니 비운다.
- 마지막 행동은 짧게 쓴다: "프로필 링크에서 무료로".

## C. 기능 업데이트 (16:9 또는 9:16, 12~15초)

- 0–2s: "새로워진 ○○." 트래킹 인, 또는 기존 불편을 템포 컷으로.
- 2–11s: 기능 하나를 깊게 보여준다. 투톤 헤드라인 → 플로우 데모 → Before/After 숫자.
- 11s–: 로고 + "지금 업데이트하기".

## D. B2B·SaaS (16:9, 30~40초)

- 훅: 고객사가 잃고 있는 비용이나 시간 수치를 숫자 히어로 ⑩로 연다 ("주 9시간.").
- 리빌 → 데이터 흐름 장면(재료가 모인다) → 대시보드 조립(카드가 날아와 그리드에 착지) → 핵심 지표 하나에 포커스 → 자동 실행.
- 폭: 연동 서비스나 기능을 리스트 롤 ⑪로 보여준다.
- 키노트 다크나 클린 화이트를 쓴다. 스프링은 약하게, eio 위주로 움직인다.

## E. AI 제품 (16:9, 25~30초)

- AI를 "마법"으로 추상화하지 않는다. 실제 입력과 실제 출력을 보여줘야 설득력이 있다.
- 그라데이션 `grad-spectrum`이 가장 잘 어울리는 카테고리다. 리빌 문장 한 곳에만 쓴다.
- 기능: 입력(대화, 문서, 사진) → 처리 1~1.5초(Pulse) → 결과 카드에 구체적인 데이터.
- 에이전트 제품이면 타임라인 장면으로 단계(검색 → 비교 → 결정 → 실행)를 순서대로 켠다.

## F. 개발자 도구·API·오픈소스 (16:9, 20~30초)

- 훅: 개발자가 공감하는 한 줄 ("또 보일러플레이트?"), 라인 리빌 ②.
- 기능: 코드·터미널 장면(설치 1줄 → 사용 3줄) → 결과 프리뷰. Before(긴 코드) / After(짧은 코드) 대비가 강력하다.
- 증거: GitHub 스타, 다운로드 수, 벤치마크. 실제 수치만 쓴다.
- 엔드카드: 설치 명령어를 모노 폰트로 크게 보여준다.

## G. 발표·데모데이·IR 오프닝 (16:9, 45~60초)

- 발표자가 말하기 전에 트는지, 말하는 동안 트는지에 따라 다르다. 말하는 동안 튼다면 글자 수를 절반으로 줄이고 컷을 길게 한다.
- 문제(시장 수치 ⑩) → 정적 → 리빌 → 해결 기능 2~3개 → 트랙션 숫자 → 비전 한 줄(그라데이션) → 로고.
- 키노트 다크가 기본이다. 무대 스크린에서 가장 강하다.

## H. 캠페인·이벤트 (9:16 또는 4:5, 15~20초)

- 혜택이 주인공이다. 무엇을, 언제까지, 어떻게 받는지 세 가지를 분명히 보여준다.
- 할인율이나 기간은 숫자 히어로로 가장 크게 둔다.
- 컬러 블록 스타일이 잘 맞는다.

## I. 부스·전시 루프 (16:9, 20~30초, 무음, 반복 재생)

- 마지막 프레임이 첫 프레임과 이어지도록 끝을 시작 상태로 되돌린다.
- 어느 시점에 봐도 제품명이 보이도록 작은 로고를 구석에 둔다.
- 멀리서 보는 전제라 글자를 더 크고 적게 쓴다. 템포 컷은 느리게(0.7초) 한다.

## 엔드카드 공통

- 순서: 로고 → 꽂히는 한 문장 → 동사형 CTA 한 줄 → URL.
- CTA는 하나만 둔다. 둘이면 행동이 갈린다.
- 마지막 1초는 움직임 없이 멈춰 둔다. 영상이 끝난 화면이 캡처되고 공유된다.
