# 스토리 템플릿 — 영상 유형별 골격

모든 템플릿은 SKILL.md의 시간 배분(훅 ≤10%, 핵심 비트 55~65%)을 따른다. 기능 수와 브리프에 맞춰 비트 개수만 조절한다. 템플릿은 출발점이지 정답이 아니다. 브리프의 "시청자가 기억할 한 문장"이 가장 강하게 드러나도록 순서를 바꿔도 된다.

## A. 서비스/앱 런칭 (16:9, 20~30초) — 기본값
| 구간 | 내용 |
|---|---|
| 0–2s | 훅: 타깃의 질문 한 줄 키네틱 타이포, 또는 결과 화면이 0.8초 스치고 "이게 어떻게?" |
| 2–5s | 문제: 구체적 상황 1개. 문장 1~2개 + 상황을 보여주는 UI 조각(쌓인 알림, 긴 폼, 흩어진 탭) |
| 5–19s | 핵심 비트 2~3개 (각 4~5초, 플로우 데모 중심). 비트 사이는 연속 변환이나 자리 비켜주기로 잇는다 |
| 19–22s | 증거: 수치 증거 또는 Before/After |
| 22–25s | 엔드카드: 로고 리빌 + 슬로건 + URL/CTA |

## B. 쇼츠/릴스 (9:16, 15~20초)
- 첫 1초에 내용 훅. 질문 타이포나 결과 화면. 로고로 시작하지 않는다.
- 핵심 비트 1~2개. 폰 목업을 화면 가운데 크게, 텍스트는 목업 위아래에.
- 무음 시청 전제: 모든 정보가 화면 텍스트에 있어야 한다.
- 상단 220px, 하단 320px은 플랫폼 UI 영역이라 비운다 (design-system.md 참고).
- 마지막 2초: 로고 + 행동 한 줄 ("프로필 링크에서 무료로").

## C. 기능 업데이트 / 신기능 소개 (10~15초)
- 0–1.5s: "새로워진 ○○" 또는 기존 불편을 한 줄로.
- 1.5–11s: 기능 하나를 깊게. 플로우 데모 → Before/After → 수치 증거.
- 11s–: 로고 + "지금 업데이트".

## D. B2B / SaaS / 대시보드 (20~40초)
- 훅: 고객사가 겪는 비용이나 시간 수치.
- 핵심: 데이터 흐름 장면(재료가 모인다) → 대시보드 조립(카드·차트가 날아와 그리드에 착지) → 핵심 지표 1개 포커스 → 액션(알림, 자동화 실행).
- 증거: 고객사 로고 월(사용자가 허락한 것만), 도입 효과 수치.
- 톤: 테크·정밀. 스프링을 약하게, eio 위주.

## E. AI 제품 (20~30초)
- AI를 "마법"으로 추상화하지 않는다. 입력과 출력을 구체적으로 보여주는 것이 설득력이 있다.
- 핵심 비트: 입력(대화, 문서, 사진) → 데이터 흐름 장면으로 추출·추론 과정을 짧게(1~1.5초) → 결과 카드에 구체 데이터.
- "AI가 추론했다"는 느낌은 원래 입력에 없던 요소가 중앙에서 새로 생성되어 결과에 합류하는 연출로 준다.
- 에이전트 제품이면 타임라인 장면으로 에이전트가 수행한 단계를 순서대로 켠다 (검색 → 비교 → 결정 → 실행).

## F. 개발자 도구 / API / 오픈소스 (15~30초)
- 훅: 개발자가 공감하는 한 줄 ("또 보일러플레이트?").
- 핵심: 코드·터미널 장면(설치 1줄 → 사용 3줄) → 결과 프리뷰. 비포(긴 코드) / 애프터(짧은 코드) 대비가 강력하다.
- 증거: GitHub 스타, 다운로드 수, 벤치마크 (실제 수치만).
- 엔드카드에 설치 명령어나 레포 주소.

## G. 데모데이 / IR / 발표 오프닝 (30~60초)
- 발표자가 말하기 전에 트는지, 말과 동시에 트는지 확인한다. 동시라면 텍스트를 절반으로 줄이고 컷을 길게.
- 문제(시장 수치 포함) → 해결 비트 2~3개 → 트랙션 수치 → 팀/비전 한 줄 → 로고.
- 트랙션·시장 수치는 사용자가 준 것만 쓴다.

## H. 캠페인 / 이벤트 / 프로모션 (10~20초)
- 혜택이 핵심 비트다: 무엇을, 언제까지, 어떻게 받는지 3요소를 명확히.
- 수치(할인율, 기간)는 가장 크게. 카운트다운 연출 가능.
- 참여 방법을 플로우 데모로 2~3단계.

## I. 부스·전시 루프 (15~30초, 무음, 반복 재생)
- 첫 프레임과 마지막 프레임이 이어지도록 끝을 시작 상태로 되돌린다.
- 어느 시점에 봐도 제품명이 보이도록 작은 로고를 구석에 상주시킨다.
- 텍스트를 크게, 적게. 멀리서 보는 전제.
