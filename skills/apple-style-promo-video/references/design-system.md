# 디자인 시스템

## 기본 규칙
- **배경**: 순백 또는 순흑. 본편은 흰색이 기본, 강조 장면이나 엔드카드는 검정. 그라데이션과 패턴은 쓰지 않는다. 브랜드가 다크 기반이면 본편을 `#0B0B0C`로 뒤집는다.
- **색은 최대 3개 + 회색**: 배경 1, 텍스트 1, 포인트 1, 보조 회색 `--sub`, 면 회색 `--soft`. 로고에서 추출한다.
- **포인트 컬러는 한 화면에 한 곳**: 핵심 키워드, 핵심 수치, CTA, 선택된 항목.
- **한 화면 한 메시지**: 헤드라인 1문장 + 시각 요소 1그룹.
- 이미지가 없는 것(아이콘, 상품)은 단순한 플랫 인라인 SVG로 직접 그린다. 외부 이미지를 핫링크하지 않는다.
- 실제 캐릭터나 브랜드 IP를 새로 그리지 않는다. 사용자가 준 에셋만 쓴다.
- 시연용 임의 데이터는 화면 구석에 `--sub` 색 18~22px로 "시연용 화면" 표기.

## 타이포

| 역할 | 16:9 (1920×1080) | 9:16 (1080×1920) | weight | 기타 |
|---|---|---|---|---|
| 헤드라인 | 88~160px | 96~150px | 800 | letter-spacing -0.04em, line-height 1.1 |
| 큰 숫자 | 160~240px | 180~260px | 800 | tabular-nums |
| 서브헤드 | 44~56px | 48~60px | 700 | |
| UI 본문 | 28~40px | 32~44px | 600 | |
| 보조·라벨 | 22~28px | 24~30px | 500 | `--sub` |

**텍스트 길이 한도** — 넘기면 문장을 쪼개 두 컷으로 나눈다
- 헤드라인: 16:9 한 줄 한글 14자 / 영문 28자, 최대 2줄. 9:16 한 줄 한글 9자, 최대 3줄.
- 한 화면 총 텍스트: 16:9 한글 40자, 9:16 한글 30자 (UI 안의 데이터 제외).
- 줄바꿈은 `<br>`로 의미 단위에서 직접 끊는다. 한 글자만 다음 줄로 넘어가지 않게 `word-break: keep-all`.
- 읽는 시간: 한글 초당 약 7~8자. 헤드라인이 머무는 시간 ≥ 글자 수 ÷ 7 + 0.5초.

## 레이아웃 그리드와 안전영역

| 포맷 | 크기 | 좌우 여백 | 상 / 하 안전영역 | 비고 |
|---|---|---|---|---|
| 16:9 | 1920×1080 | 160px | 100 / 100 | 발표·유튜브 |
| 9:16 | 1080×1920 | 80px | 220 / 320 | 쇼츠·릴스 UI가 덮는 영역 비움 |
| 1:1 | 1080×1080 | 90px | 90 / 90 | 피드 |
| 4:5 | 1080×1350 | 90px | 110 / 110 | 인스타 피드 |

- 16:9는 12단 그리드(칼럼 gap 24px). 텍스트+UI 장면은 텍스트 5단 / UI 7단으로 나눈다.
- 9:16·4:5는 세로 스택: 헤드라인(위) → UI(가운데, 화면 폭 80%) → 보조(아래).
- 중앙 정렬 장면과 좌측 정렬 장면을 섞지 않는다. 영상 전체에서 기본 정렬 하나를 정한다 (헤드라인 단독 장면은 중앙, UI 동반 장면은 좌측 텍스트).
- 여백을 두려워하지 않는다. 화면의 40% 이상이 비어 있어도 괜찮다.

## UI 요소
- **카드**: radius 28~48px, 그림자 `0 24px 80px rgba(0,0,0,.10)` + 헤어라인 `0 0 0 1px rgba(0,0,0,.05)`.
- **칩/태그**: pill, `--soft` 배경, 핵심 칩만 포인트 컬러.
- **폰 목업**: radius 56px 검정 프레임(베젤 14px), 화면 비율 19.5:9. 16:9에서 높이 820px 안팎.
- **브라우저 목업**: 상단 바 52px(점 3개 + 주소창), radius 20px. 웹 서비스는 폰보다 이게 맞다.
- **대비**: 포인트 컬러 배경 위의 하이라이트는 반전(검정 바탕 + 포인트 글자).
- 조판 UI는 실제 서비스처럼 보이도록 데이터를 구체적으로 채운다 (이름, 시간, 가격, 상태). 빈 박스나 lorem ipsum 금지.
