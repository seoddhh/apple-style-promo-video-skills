# 디자인 시스템

목차: 스타일 프리셋 · 기본 규칙 · 색 토큰 · 레이아웃과 안전영역 · UI 요소 · Liquid Glass

타이포 크기, 굵기, 자간, 카피는 [typography-playbook.md](typography-playbook.md)에 있다.

## 스타일 프리셋

`<body class="style-…">` 하나로 토큰을 바꾼다. 장면 하나만 반전하려면 장면에 `light`, `dark`, `color` 클래스를 붙인다.

| | 키노트 다크 `style-keynote` (기본) | 클린 화이트 `style-clean` | 컬러 블록 `style-color` | 템포 키네틱 `style-tempo` |
|---|---|---|---|---|
| 레퍼런스 | 애플 이벤트 키노트, 프로 제품 필름 | apple.com 제품 페이지 | 아이팟·아이폰 컬러 캠페인 | 애플 쇼츠·SNS 광고 |
| 배경 | #000 | #FFF, UI 장면은 #F5F5F7 | `--brand` 풀스크린 | 검정 기본 + 흰 장면 교차 |
| 글자 | #F5F5F7 / 회색 #86868B | #1D1D1F / 회색 #6E6E73 | #FFF / 흰색 80% | 다크와 같음 |
| 시그니처 | 정적 → 트래킹 인, 그라데이션, 빛 스윕 | 투톤 헤드라인, 떠 있는 UI 카드 | 거대한 흰 글자, 장면마다 다른 브랜드 톤 | 템포 컷, 단어 교체, 글자 속 줌 |
| 컷 길이 | 2.5~4초 | 3~4초 | 2~3초 | 0.4~2초 |
| 전환 | 디졸브, 하드컷 + 정적 | 디졸브 | 하드컷 (장면 경계에서만 색 변경) | 하드컷, 글자 속 줌 |
| 어울리는 제품 | AI, 개발자 도구, 프로·B2B | 생산성, SaaS, 커머스 | 소비자 앱, 라이프스타일, 캠페인 | 쇼츠·릴스, 이벤트 |

- **컬러 블록:** `--brand`는 흰 글자와의 대비가 3:1 이상인 진한 색이어야 한다. 밝은 브랜드 컬러라면 명도를 낮춘 버전을 쓴다. 배경색을 바꿀 때는 1초에 3번 넘게 바꾸지 않는다 (깜빡임).
- **템포 키네틱:** 다크와 라이트를 교차할 때는 장면 경계에서 바꾸고, 글자 속 줌(무브 ⑭)으로 이어 주면 가장 매끄럽다.
- 브랜드가 원래 다크 기반이면 클린 화이트를 골라도 UI 장면만 라이트로 두고 타이포 장면은 다크로 두는 혼합을 제안할 수 있다.

## 기본 규칙

- **색은 배경, 글자, 포인트 3개에 회색을 더한 것까지만 쓴다.** 포인트 컬러는 로고에서 뽑는다.
- **포인트 컬러는 한 화면에 한 곳**에만 쓴다: 꽂히는 단어, 핵심 수치, 선택된 UI, CTA 중 하나.
- **배경에 그라데이션이나 패턴을 넣지 않는다.** 그라데이션은 글자 안에서만 쓴다 (typography-playbook ⑦).
- **브랜드는 내용 뒤에 선다.** 로고는 엔드카드에서 한 번만 쓴다. 브랜드 느낌은 색과 카피 말투로 낸다.
- 아이콘은 단순한 플랫 인라인 SVG로 직접 그린다. 선 굵기는 옆 글자 굵기와 맞춘다. 외부 이미지를 핫링크하지 않는다.
- 캐릭터나 다른 브랜드 IP를 새로 그리지 않는다. 사용자가 준 에셋만 쓴다.
- 시연용 임의 데이터를 썼다면 화면 구석에 `--sub` 색 22px로 "시연용 화면"이라고 표기한다 (template의 `#demoNote`).

## 색 토큰

| 토큰 | 용도 |
|---|---|
| `--bg` / `--ink` / `--sub` | 배경 / 글자 / 보조 글자 (프리셋이 정한다) |
| `--soft` | 칩·면 배경, 라이트 UI 장면의 배경 |
| `--card` / `--line` / `--shadow` | 카드 면, 헤어라인, 그림자 |
| `--accent` / `--accent2` | 브랜드 포인트 면·선, `grad-brand` 그라데이션의 두 색 |
| `--accent-ink` | 포인트 색 **글자**. 배경 대비 4.5:1 이상 |
| `--brand` | 컬러 블록 배경 |

- 노랑·연두·하늘색처럼 밝은 포인트 컬러는 흰 배경 위에서 글자로 쓰지 못한다. 면으로만 쓰고, 글자에는 명도를 낮춘 `--accent-ink`를 쓴다.
- 회색을 새로 만들지 않는다. 토큰에 있는 회색만 쓴다.

## 레이아웃과 안전영역

| 포맷 | 크기 | 좌우 여백 | 상 / 하 안전영역 |
|---|---|---|---|
| 16:9 | 1920×1080 | 160px | 100 / 100 |
| 9:16 | 1080×1920 | 80px | 220 / 320 (쇼츠·릴스 UI가 덮는 영역) |
| 1:1 | 1080×1080 | 90px | 90 / 90 |
| 4:5 | 1080×1350 | 90px | 110 / 110 |

- **타이포 단독 장면은 정중앙**에 둔다 (`.frame.center`). 애플 키노트 문법이다.
- **글자 + UI 장면은 좌측 텍스트 5단 / 우측 UI 7단**으로 나눈다 (`.split`). 세로 포맷에서는 위 글자, 아래 UI로 자동으로 쌓인다.
- 화면의 40% 이상이 비어 있어도 괜찮다. 오히려 그래야 애플답다.
- 관련 있는 것은 여백으로 묶고, 관련 없는 것은 떨어뜨린다.

## UI 요소

제품 UI 장면은 "이게 뭘 해주는지"를 증명하는 곳이다. 타이포가 혹하게 만들고, UI가 믿게 만든다.

- **카드:** radius 28~48px, `--shadow` 그림자에 헤어라인 `0 0 0 1px var(--line)`. 화면에 떠 있는 느낌이 나도록 배경은 `--soft`로 둔다.
- **칩·태그:** pill 모양에 `--soft` 배경을 쓰고, 핵심 칩 하나만 `.pill.on`(포인트 컬러)으로 둔다.
- **폰 목업:** radius 56px 검정 프레임(베젤 14px), 화면 비율 19.5:9, 16:9 기준 높이 820px 안팎. 상단 센서 영역은 작은 알약 모양으로 그린다.
- **브라우저 목업:** 상단 바 52px(점 3개와 주소창), radius 20px. 웹 서비스에는 폰보다 이게 맞다. 주소창에 실제 도메인을 넣는다.
- **목업 없이 떠 있는 UI:** 핵심 화면 조각(카드, 리스트, 입력창)만 크게 잘라 띄운다. 애플 제품 페이지가 자주 쓰는 방식이고, 글자가 커서 영상에서 가장 잘 읽힌다. **기본값으로 쓴다.**
- 스크린샷을 받으면 목업 안에 넣거나 카드 모양으로 잘라 넣는다. 받은 화면에서 핵심 영역만 크롭해 확대하는 게 전체 화면을 작게 보여주는 것보다 낫다.
- 조판 UI는 실제 서비스처럼 보이도록 구체적인 데이터를 채운다 (이름, 시간, 가격, 상태). 빈 박스나 lorem ipsum은 쓰지 않는다. 실존 인물 대신 가상의 이름을 쓴다.
- 스토어 배지를 쓰려면 사용자가 준 공식 배지 파일을 그대로 쓴다. 직접 그리면 가짜처럼 보인다. 파일이 없으면 텍스트 CTA로 대신한다.

## Liquid Glass

지금의 애플 UI 재질이다. 지도, 사진, 스크롤되는 목록 위에 떠 있는 **컨트롤**(탭 바, 툴바, 플레이어 컨트롤, 떠 있는 버튼)에 쓰면 화면이 단번에 "요즘 애플"처럼 보인다.

```css
.glass{background:rgba(255,255,255,.22);
  backdrop-filter:blur(22px) saturate(180%);-webkit-backdrop-filter:blur(22px) saturate(180%);
  box-shadow:inset 0 1px 0 rgba(255,255,255,.75),inset 0 0 0 1px rgba(255,255,255,.28),0 10px 34px rgba(0,0,0,.14);
  border-radius:999px}
```

- **유리 밑으로 내용이 지나가야 효과가 보인다.** 흰 배경 위의 유리는 회색 알약일 뿐이다. 유리 아래 콘텐츠를 eio로 천천히 스크롤하면 굴절이 살아난다.
- 콘텐츠 카드에는 쓰지 않는다. 한 화면에 유리 요소 그룹은 하나만 둔다.
- 밝은 사진 위에서는 유리 뒤에 35% 어두운 층을 깔아 글자를 읽히게 한다.
