# 타이포그래피 플레이북 — 이 스킬의 핵심

3D 제품 렌더가 없는 애플풍 영상은 **글자가 제품 역할을 한다.** 애플 키노트와 광고에서 반복되는 타이포 문법을 그대로 빌려온다.

목차: 원칙 · 리듬 · 시그니처 무브 14 · 순간별 무브 선택 · 카피 공식 · 하지 말 것

모든 헬퍼는 `assets/template.html`에 들어 있다. `lt`는 장면 로컬 시간이고, 함수는 장면의 `draw(lt, t)` 안에서 호출한다.

---

## 원칙

**1. 크게. 생각보다 훨씬 크게.**

| 역할 | 16:9 | 9:16 | weight | letter-spacing | line-height |
|---|---|---|---|---|---|
| 히어로 (제품명, 한 단어, 큰 숫자) | 200~320px | 170~260px | 700~800 | -0.04em | 1.0 |
| 헤드라인 | 120~160px | 110~140px | 700 | -0.03em | 1.05 |
| 서브헤드 (둘째 문장, 회색) | 56~72px | 56~68px | 600 | -0.015em | 1.15 |
| 아이브로 (헤드라인 위 라벨) | 30~36px | 34~40px | 600 | 0 | — |
| UI 본문 | 28~40px | 32~44px | 500~600 | 0 | — |

- 위계는 크기 차이로 만든다. 히어로와 서브는 3배 이상 차이 나게 한다. 비슷한 크기가 두 개 있으면 밋밋해진다.
- 500 미만의 얇은 굵기는 쓰지 않는다. 영상을 압축할 때 가장 먼저 뭉개진다.
- 서체는 Pretendard 하나로 충분하다 (SF Pro와 비율이 가깝다). 브랜드 서체가 있으면 히어로에만 쓴다.

**2. 한 화면에 한 문장.** 문장이 둘이면 컷을 나누거나 투톤(무브 ⑥)으로 위계를 준다. 16:9는 한 줄에 한글 12자, 9:16은 8자 안팎이다. 줄바꿈은 `<br>`로 의미 단위에서 직접 끊고, `word-break: keep-all`을 쓴다.

**3. 색은 둘, 강조는 하나.** 글자는 `--ink` 하나에 보조로 `--sub`(회색)만 쓴다. 색이나 그라데이션은 꽂히는 한 단어에만 준다.

**4. 여백이 고급스러움이다.** 화면의 절반 이상이 비어 있어도 된다. 글자를 정중앙 또는 좌측 상단 그리드에 두고, 한 영상 안에서 정렬 방식을 섞지 않는다.

**5. 마침표는 리듬이다.** 애플 카피는 마침표로 끊는다. "Pro. Beyond." 한국어도 "빠르다. 가볍다." 처럼 짧게 끊고 마침표를 찍는다. 느낌표는 쓰지 않는다.

## 리듬

애플 영상은 **느림 → 빠름 → 정적 → 폭발**을 반복한다. 같은 속도로 30초를 끌면 지루하다.

- **템포 구간:** 단어 하나에 0.35~0.5초씩 하드컷한다. 긴장을 쌓는 훅에 쓴다.
- **정적:** 리빌 직전에 빈 화면을 0.3~0.6초 둔다. 이 정적이 있어야 리빌이 크게 느껴진다.
- **리빌:** 제품명이나 꽂히는 문장이 천천히(1.2~1.8초) 등장해 2초 이상 머문다.
- **읽는 시간:** 문장은 글자 수 ÷ 7 + 0.6초 이상 머문다. 템포 컷의 단어 하나는 예외다.
- 등장은 0.5~0.9초, 퇴장은 0.3~0.4초로 한다. 퇴장이 등장보다 빠르다. linear 이징은 쓰지 않는다.

## 시그니처 무브 14

### ① 단어 빌드 `words(el, lt, start, gap=.12)`
단어가 하나씩 아래에서 떠오르며 블러가 걷힌다. 가장 기본이 되는 헤드라인 등장이다.
```html
<h1 class="head" id="h1"><span class="w">회의는</span><span class="w">끝났다.</span></h1>
```
```js
words($('h1'), lt, .2);
```

### ② 라인 마스크 리빌 `lines(el, lt, start, gap=.1)`
줄마다 보이지 않는 선 아래에서 밀려 올라온다. 단어 빌드보다 단단하고 고급스럽다. 2~3줄짜리 선언문에 쓴다.
```html
<h1 class="head" id="h2"><span class="line"><span>일은 그대로.</span></span><span class="line"><span class="sub">시간은 절반.</span></span></h1>
```
```js
lines($('h2'), lt, .2, .18);
```

### ③ 트래킹 인 `trackIn(el, lt, start, dur=1.6)`
넓게 벌어진 자간이 좁혀지며 선명해진다. 제품명 리빌, 영화 타이틀 같은 순간에 쓴다. 영상 전체에서 1~2번만 쓴다.
```js
trackIn($('name'), lt, .3);          // 자간 .4em → -.03em, 블러 8px → 0
```

### ④ 템포 컷 `tempo(el, lt, start, list, each=.42)`
화면 중앙의 한 단어가 박자마다 바뀐다. 컷마다 살짝 튀어나왔다가(scale 1.05→1) 자리를 잡는다. 훅과 기능 나열에 강하다.
```js
tempo($('beat'), lt, .1, ['메일.', '메신저.', '노션.', '캘린더.', '<span class="grad grad-brand">한 곳에.</span>'], [.4,.4,.4,.55]);
```
- `each`에 배열을 넘기면 단어마다 길이를 다르게 줄 수 있다. 마지막 단어 앞에서 조금 길게 끌면 착지감이 생긴다.
- 배경색을 컷마다 바꾸지 않는다. 화면이 번쩍여 깜빡임 검사에 걸린다.

### ⑤ 단어 교체 `swap(el, lt, times)`
앞 문구는 고정되고, 아래 줄의 단어만 위로 굴러가며 바뀐다. 기능 세 가지를 한 문장 틀로 보여줄 때 쓴다.
```html
<h1 class="head" id="h"><span class="line"><span>더</span></span>
  <span class="line"><span class="swap" id="sw"><span><b>빠르게.</b><b>정확하게.</b><b class="grad grad-brand">쉽게.</b></span></span></span></h1>
```
```js
lines($('h'), lt, .4, .15);          // .swap을 .line 안에 넣어야 첫 단어도 함께 등장한다
swap($('sw'), lt, [1.4, 2.6]);       // 1.4초에 두 번째 단어, 2.6초에 세 번째 단어
```

### ⑥ 투톤 헤드라인
첫 문장은 `--ink`, 둘째 문장은 `--sub` 회색으로 쓴다. apple.com 제품 페이지의 문법이다. "제품명. 무엇을 해주는지." 구성에 딱 맞는다.
```html
<h1 class="head"><span class="line"><span>Notely.</span></span><span class="line"><span class="sub">회의록은 이제 저절로.</span></span></h1>
```
둘째 줄을 0.3초 늦게 등장시킨다 (`lines`의 gap .3).

### ⑦ 그라데이션 글자 `.grad` + `gradFlow(el, t)`
글자 안에 그라데이션을 채우고 천천히 흐르게 한다. **꽂히는 한 단어에만, 영상 전체에서 1~2곳만** 쓴다.
```html
<span class="grad grad-spectrum" id="g">Intelligence.</span>
```
```js
gradFlow($('g'), t);                 // 전역 시간 t로 흐르면 장면이 바뀌어도 이어진다
```
- 프리셋은 3가지다. `grad-spectrum`(파랑→보라→분홍→주황, AI·창의), `grad-metal`(흰색→회색, 다크 배경 전용, 프로·정밀), `grad-brand`(`--accent`→`--accent2`).
- `words()`로 쪼개면 단어마다 그라데이션이 끊긴다. 그라데이션 글자는 한 덩어리로 등장시킨다 (`lines`, `trackIn`, `scaleIn`).

### ⑧ 빛 스윕 `.sheen` + `sheen(el, lt, start)`
글자 위로 빛이 한 번 지나간다. 리빌이 끝나고 머무는 동안 한 번 쓴다. 금속 질감이나 "새것" 느낌을 준다.
```js
scaleIn($('name'), lt, .2); sheen($('name'), lt, 1.6, 1.2);
```

### ⑨ 스케일 인 `scaleIn(el, lt, start, dur=1.2, from=1.12)`
살짝 큰 크기에서 블러와 함께 제자리로 내려앉는다. 로고, 숫자, 그라데이션 문장의 등장에 쓴다.

### ⑩ 숫자 히어로 `countUp(el, lt, start, to, {dur, from, dec, suffix})`
화면을 채우는 숫자가 카운트업하고, 단위는 작게, 의미는 아래에 회색으로 둔다.
```html
<div class="hero num"><span id="n">0</span><span class="unit">분</span></div>
<p class="subhead sub">견적 하나에 걸리는 시간</p>
```
```js
countUp($('n'), lt, .3, 3, {from: 120, dur: 1.4});      // 120분 → 3분 (줄어드는 숫자도 강력하다)
```
수치는 사용자가 준 것만 쓴다. 없으면 이 무브를 쓰지 않는다.

### ⑪ 리스트 롤 `listRoll(el, lt, times)`
기능 목록이 세로로 굴러가고, 가운데 줄만 선명하며 위아래는 흐리다. "그리고 이것도, 이것도" 하는 폭을 보여준다.
```html
<div class="roll-mask"><div class="roll" id="r"><div>실시간 번역</div><div>자동 요약</div><div>할 일 추출</div><div>캘린더 연동</div></div></div>
```
```js
listRoll($('r'), lt, [1.0, 1.7, 2.4]);
```

### ⑫ 기능 월 `wall(el, lt, start, {gap, focus, focusAt})`
기능 이름 10~20개가 크기를 섞어 화면을 채우며 무작위 순서로 켜진다. 그다음 하나만 남고 나머지는 어두워진다. 키노트 마무리의 "and so much more" 장면이다.
```html
<div class="wall" id="wl"><span class="l">자동 요약</span><span>번역</span><span class="l">검색</span>…</div>
```
```js
wall($('wl'), lt, .1, {gap: .05, focus: 2, focusAt: 2.2});
```

### ⑬ 정적 비트
리빌 앞에 아무것도 없는 장면을 둔다. 코드는 빈 장면 하나다.
```js
{id:'s-hush', role:'reveal', dur:.5, draw(){}}
```
`style-keynote`이면 완전한 검정 화면이다. 앞 장면의 마지막 단어가 사라지고, 0.5초 숨을 고르고, 제품명이 나온다.

### ⑭ 글자 속으로 줌 `zoomThrough(el, lt, start, dur=.9, max=100)`
문장 끝의 마침표(또는 I, l, 1 같은 굵은 세로획)를 향해 가속하며 확대된다. 화면이 글자색으로 가득 차면 다음 장면으로 하드컷한다. 다음 장면의 배경은 그 글자색으로 둔다. 다크에서 화이트로 넘어갈 때 쓰며, 영상에서 한 번만 쓴다.
```html
<h1 class="head" id="z">정리, 끝<span class="dot" id="zdot">.</span></h1>
```
```js
// measure()에서: setOrigin($('z'), $('zdot'))   ← 마침표 중심을 transform-origin으로
zoomThrough($('z'), lt, 1.2);
```

### 보너스: 글자 → UI 변신
헤드라인 속 키워드 하나가 떨어져 나와 아래 UI 카드의 칩이나 입력값 자리에 착지한다. 타이포 장면과 제품 장면을 인과로 잇는다. 구현은 motion-recipes.md의 「연속 변환」(slot 기법)을 따르고, 날아가는 동안 `fontSize`와 칩 배경 opacity를 같은 k로 lerp한다.

### 퇴장 `leave(el, lt, start, dur=.35)`
위로 30px 밀려나며 사라진다. 장면을 디졸브로 넘기지 않고 글자만 먼저 치울 때 쓴다. 등장 함수가 transform을 쓰는 요소에는 걸지 말고, 감싸는 부모에 건다.

## 순간별 무브 선택

| 순간 | 1순위 | 대안 | 피할 것 |
|---|---|---|---|
| 첫 1~3초 훅 | ④ 템포 컷 (문제 나열) | ② 라인 리빌 (질문 한 줄) | 로고로 시작 |
| 문제 | ② 라인 리빌, 회색 둘째 줄 | ⑪ 리스트 롤 (불편 나열) | 긴 설명 |
| 리빌 | ⑬ 정적 → ③ 트래킹 인 → ⑧ 빛 스윕 | ⑨ 스케일 인 + ⑦ 그라데이션 | 파티클, 바운스 |
| 기능 소개 | ⑥ 투톤 헤드라인 + UI 장면 | ⑤ 단어 교체 | 기능명만 나열 |
| 기능 → UI 전환 | 글자 → UI 변신 | ⑭ 글자 속 줌 | 와이프 남발 |
| 폭 | ⑫ 기능 월 | ⑪ 리스트 롤 | 아이콘 그리드만 |
| 증거 | ⑩ 숫자 히어로 | ⑥ 투톤 (Before/After 문장) | 지어낸 수치 |
| 엔드카드 | ⑨ 로고 → ② 꽂히는 문장(⑦) → CTA | ③ 트래킹 인 | CTA 여러 개 |

**엔드카드 락업 타이밍 (3초):** 0.0~1.0초 로고 `scaleIn` → 0.5~1.4초 꽂히는 한 문장 `lines` (그라데이션 가능) → 1.4~1.9초 CTA·URL 페이드 (`--sub`, 36~44px) → 끝까지 정지.

## 카피 공식

카피가 약하면 무브를 아무리 잘 써도 혹하지 않는다. 아래 공식 중 2~3개를 골라 영상 전체를 쓴다.

| 공식 | 예시 | 쓰는 곳 |
|---|---|---|
| 3박자 + 착지 | 빠르다. 정확하다. 그리고, 쉽다. | 훅, 기능 요약 |
| 대비 | 일은 그대로. 시간은 절반. | 문제 → 해결 |
| 제품명. 한 줄. | Notely. 회의록은 이제 저절로. | 리빌 (투톤) |
| 숫자 선언 | 3분. 견적 하나에 걸리는 시간. | 증거 |
| 질문 훅 | 아직도 엑셀로 정리하세요? | 첫 화면 |
| "이제," 전환 | 이제, 사진 한 장이면 됩니다. | 문제 → 리빌 |
| 나열 → 수렴 | 메일. 메신저. 노션. → 한 곳에. | 템포 컷 |
| 짧은 단언 | 설정은 없습니다. 정말로. | 차별점 |
| 감각 동사 | 찍으면, 끝. / 말하면, 정리. | 기능 헤드라인 |

- **형용사 대신 숫자와 동사를 쓴다.** "혁신적인", "최고의", "스마트한"은 아무 말도 하지 않는다.
- **기능명이 아니라 결과를 쓴다.** "AI 자동 분류" ✗ → "알아서 정리됩니다." ✓
- **같은 대상은 같은 단어로 부른다.** 일정/플랜/코스를 섞지 않는다.
- **말투는 하나로 통일한다.** 한다체("끝났다.")나 합니다체("끝납니다.") 중 하나를 고른다. 짧은 명사형 마무리("한 곳에.")는 어느 쪽과도 어울린다.
- 제품명과 고유명사는 원래 표기대로 쓴다. 한국어 사이에 영문 제품명이 있어도 된다.
- **CTA는 동사 한 줄로 쓴다.** "무료로 시작하기", "notely.app에서 만나보세요". 귀여운 말투("가보자고!")는 쓰지 않는다.

## 하지 말 것

- 한 화면에 문장 두 개, 색 세 개, 서체 세 개
- 배경 그라데이션, 패턴, 이모지, 3D 텍스트, 글자 외곽선, 그림자 진한 글자
- 모든 장면에 같은 무브 반복. 영상 하나에 시그니처 무브 5~7종을 섞는다
- 그라데이션 글자를 3곳 이상 쓰기
- 파티클 폭발, 통통 튀는 캐릭터, 흔들리는 글자
- 읽을 시간이 없는 긴 문장을 템포 컷으로 넘기기
